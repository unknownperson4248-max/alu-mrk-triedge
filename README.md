# Alu MRK TriEdge Ltd website

Static website for Alu MRK TriEdge Ltd, aluminium and glass systems in Cyprus. English and Greek.

- `index.html`: the whole site (styles and scripts inline)
- `img/`: photos and logo

## Deploy on Cloudflare Pages
Connect this repository in Cloudflare Pages. Framework: None. Build command: empty. Output directory: `/`.
